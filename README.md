
###  **Project Overview: Bright Coffee Shop Sales Analysis**

This project presents a comprehensive sales analysis of historical transactional data from **Bright Coffee Shop**. The objective is to generate actionable business insights that support a newly appointed CEO in improving revenue performance, identifying growth opportunities, and optimizing product strategy.

The analysis focuses on uncovering trends in sales performance, customer purchasing behavior, and product category performance to drive data-informed decision-making.

###  **Key Objectives**

* Analyze revenue trends over time
* Evaluate product category performance
* Identify top-performing segments
* Support strategic decision-making with data insights
* Highlight opportunities to increase sales and customer engagement

###  **Outcome**

This project delivers a visually interactive dashboard and a set of insights that can help leadership:
